# Spec Delta

## ADDED Requirements

### Requirement: CSS 与 JS 断点一致性
系统的 CSS 布局切换阈值 SHALL 与 JS 断点系统（isMobile < 992px）保持一致，不得存在两套不一致的断点造成布局盲区。

#### Scenario: 全屏弹窗布局不依赖独立断点
- **WHEN** 弹窗在任意视口宽度下进入全屏模式（isMobile 为真，含"电脑窗口"模式下的 ~980px 视口）
- **THEN** 弹窗内容区按可用高度拉伸布局生效
- **AND** 内容输入区域不得退化为默认行数（约 2~3 行）

#### Scenario: 盲区宽度下行为正确
- **WHEN** 视口宽度处于 768px ~ 991px 区间
- **THEN** JS 判定的设备类型与 CSS 应用的布局样式相互一致
- **AND** 不出现"JS 走移动分支、CSS 走桌面分支"的错配

### Requirement: 移动端视口高度
系统 SHALL 使用动态视口高度（而非固定 100vh）计算应用根容器与全屏弹窗的高度，使页面跟随浏览器地址栏的收起与展开。

#### Scenario: 地址栏可见时不遮挡内容
- **WHEN** 移动端浏览器处于非全屏状态（地址栏/工具栏可见）
- **THEN** 页面底部内容完整可见，不被浏览器工具栏遮挡
- **AND** 主内容区滚动条的末端可完整滚动到达

#### Scenario: 地址栏收起时占满屏幕
- **WHEN** 移动端浏览器地址栏收起（视口变高）
- **THEN** 应用根容器高度动态增长并占满可见屏幕
- **AND** 不出现底部留白

#### Scenario: 老旧内核降级
- **WHEN** 浏览器不支持动态视口单位（dvh）
- **THEN** 系统使用 JS 计算的视口高度作为降级方案
- **AND** 页面高度仍然跟随可视区域变化

#### Scenario: 桌面端不受影响
- **WHEN** 在桌面浏览器（视口高度恒定）访问
- **THEN** 页面布局与高度行为与迁移前一致
